# Iteration 04 Context

Iteration 04 is the first thesis-grade experimental setup iteration.

The main limitation after Iteration 03 is that the project still relies on a toy/manual setup for most evidence and evaluation. That is not yet sufficient for thesis-grade experimental support.

This iteration is therefore core experimental work, not final packaging:

- move from toy-only corpus support to a small curated real scholarly corpus
- document corpus provenance and acquisition logic
- run repeatable baseline comparisons on that curated setup
- produce artifacts that can later support thesis chapter writing

This iteration must still preserve the current local architecture and the framing of the system as a prior-art risk assessor relative to a selected corpus and retrieval strategy.

The final constrained pass inside Iteration 04 is not a new architecture iteration. It exists only to make the curated experimental setup more credible before freezing core development.

Stop condition:

- after this pass, no more core logic changes should be needed unless a critical bug is found
- remaining work after this pass should be thesis-oriented packaging and presentation
