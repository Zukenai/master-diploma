# Iteration 03 Context

This is the target architecture iteration for the core technical contribution of the thesis.

The system should still remain inspectable and evidence-grounded even as retrieval quality improves.

Iteration 03 is motivated by Iteration 02 findings on the toy corpus:

- retrieval architecture is richer, but verdicts are still overconfident on some cases
- far cases can still get elevated scores from semantic drift in a tiny corpus
- lexical trap cases still expose insufficient facet discrimination
- the project still lacks a repeatable comparison harness across retrieval modes
