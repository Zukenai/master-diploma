# Roadmap

## Iteration 01 — MVP Baseline Scaffold

Goal:

- deliver a runnable local baseline with planning artifacts, sample data, sparse retrieval, rule-based scoring, explanation, CLI, docs, and tests

Status:

- active implementation scope

## Iteration 02 — Retrieval Upgrade

Goal:

- improve retrieval architecture without breaking the MVP baseline

Planned focus:

- retriever interfaces stabilization
- dense retriever stub or initial implementation
- hybrid fusion design
- reranker interface
- better config management
- improved evidence model

Status:

- planning only

## Iteration 03 — Balanced Architecture and Evaluation Harness

Goal:

- reach a thesis-ready architecture suitable for core experimental description

Planned focus:

- dense retrieval
- hybrid retrieval
- reranking
- improved scoring features
- claim-aware overlap logic
- evaluation harness
- baseline comparisons

Status:

- planning only

## Iteration 04 — Thesis and Experiment Support

Goal:

- polish the repository for experiments, reproducibility, and chapter-friendly outputs

Planned focus:

- richer docs
- experiment scripts
- reproducibility notes
- ablation support
- thesis-oriented result packaging

Status:

- planning only
